# KnowYou 1.1.2 Local Memory Workflow Campaign Plan

Date: 2026-06-01

## Audience

- Primary: developers, AI coding-agent users, founders, and heavy knowledge workers who lose context across tools.
- Secondary: Mac productivity users, local-first/privacy-first builders, early AI agent infrastructure users.

## Goal

Awareness + TestFlight/download intent + feedback from users who already use Claude Code, Codex, Cursor, OpenClaw, or other agent workflows.

## Core Angle

Your AI agents are powerful, but they still do not know what you did yesterday. KnowYou gives them a local memory layer built from the work context already on your Mac.

## Atomic Ideas

1. The first-run problem is fixed: no blank state, start with a real source-linked Demo Day.
2. Your last 3 days can become local memories automatically after setup.
3. Every memory links back to evidence, so the diary is inspectable instead of magical.
4. A broken or missing diary engine is now visible and fixable from the toolbar.
5. The bigger workflow is emerging: Diary + Todo + Other Source + My Wiki + agent context.
