I use AI coding agents every day, and the annoying part is not the model quality anymore.

It is context.

Every tool starts from zero unless I explain what I did yesterday, what decision led to the current code, what notes matter, and which source to trust.

So I built KnowYou, a local-first macOS app that turns the context already on your Mac into a source-linked daily memory.

The new build focuses on the first-run workflow:

- it opens with a real Demo Day, so you can see how memories link back to sources

- memories are stored locally as Markdown
- it includes Todo / source evidence / engine status instead of just a plain journal

The goal is to make your personal/project context usable by future AI agents without sending everything to a cloud memory service.
