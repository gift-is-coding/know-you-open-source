## Maker First Comment

Hi Product Hunt, I'm Tianfu, maker of KnowYou.

I built KnowYou because I kept losing the shape of my workday. By evening, I could remember a few big tasks, but not the useful connective tissue: which threads I touched, what context led to a decision, what I copied while researching, or which notifications pulled me into something important.

KnowYou is a local-first macOS app that quietly captures daily computer context and turns it into a readable journal.

What it does today:

- Captures clipboard context with privacy filtering before persistence
- Imports local macOS Notification Center history when permission and schema allow it
- Stores events in local SQLite
- Generates a story-first daily diary with source-linked evidence
- Writes both Markdown and structured JSON files to your Mac
- Supports optional summarizers via OpenAI API, Codex Auth, Claude Code CLI, Codex CLI, Gemini CLI, or local fallback
- Lets you sync daily Markdown memories into Obsidian or OpenClaw

The design principle is simple: first give you the story of the day, then let you inspect the raw sources only when you need proof.

KnowYou is not a cloud diary, not a team activity tracker, and not a surveillance dashboard. It is meant for people who want a private memory layer for their own computer work.

I'd love feedback on three things:

1. Does the local-first privacy model feel clear enough?
2. Which daily context sources would be most valuable next?
3. Does the generated diary feel like something you would actually review at the end of the day?

Thanks for taking a look.
