# KnowYou Daily Work Proof Story Campaign Plan

Date: 2026-06-03

## Audience

- Primary: AI-heavy builders, developers, knowledge workers, managers who need status clarity, solo founders.
- Secondary: productivity communities, local-first/privacy audiences, Chinese tech/productivity communities.

## Goal

Awareness + product downloads. The post should feel like a human story first, and a product pitch second.

## Core Angle

When your workday is scattered everywhere, KnowYou gives you a local daily memory you can point to.

## Atomic Ideas

1. "Did you actually work today?" is a bad feeling; KnowYou makes the day visible.
2. A daily memory is useful for status updates, weekly reviews, and AI agents.
3. The key is source evidence, not just a generated summary.
4. Local-first matters because work memory is private.
5. This is not employee surveillance; it is self-owned context.

## Channels

- English: X, LinkedIn, Reddit, Dev.to, Indie Hackers if account permissions allow, Hacker News only if login exists.
- Chinese: 即刻, V2EX, 少数派 / 微信, Bilibili dynamic if logged in.
- Product Hunt: skip for this daily story; use only for major release requests.
