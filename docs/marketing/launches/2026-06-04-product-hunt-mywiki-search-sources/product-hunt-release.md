## Release Description

KnowYou now goes beyond a daily work diary.

This release turns the context already collected on your Mac into a more useful local memory layer:

- MyWiki builds a living wiki from your daily messages, notes, logs, and source evidence
- semantic search helps you find the decision, source, todo, or memory you need later
- richer Sources make it clearer where each memory came from and what should be included
- local-first storage keeps your work context on your Mac
- AI agents can reuse the context instead of starting from zero every session

The goal is simple: your day should become reusable context, not scattered fragments.

## Maker Comment

I built KnowYou because I kept repeating the same context to AI coding agents.

The work was already on my Mac: notes, copied snippets, coding logs, app activity, source evidence, todos, and project decisions. But every agent still started from zero.

This release adds the pieces that make that memory more reusable:

- MyWiki: daily context becomes a living local wiki
- Search: find memories and sources after the day is gone
- Sources: include more of the apps and logs that explain what actually happened

This is not employee monitoring. It is self-owned context for people who work across many tools and want AI agents to understand more without uploading everything to a cloud memory service.

I would love feedback from builders who use Claude Code, Codex, Cursor, OpenClaw, or other agent workflows every day.
